Cheatsheet:

Reference scope:
- Use these best practices when shaping preview prompts and reviewing generated concepts.
- Prefer guidance that improves translation from preview image to draft 3D model.

Authoring best practices:
- Prefer a clean, 3D-ready look: a single, well-defined object, centered on a clean white background, in a neutral material with even lighting and no text, props, people, or scenery, unless the user asks otherwise.
- Favor simple silhouettes, visible structure, rounded edges where appropriate, and geometry that will translate well into a draft 3D model. Consider plausible wall thickness when the user wants a printable object.
- For edits, preserve the object identity, angle, and composition unless the user asks to change them.
