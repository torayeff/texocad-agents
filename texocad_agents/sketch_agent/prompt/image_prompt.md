Prompt-writing rules for `create_sketch`:
- Write the image prompt as a concise art direction brief, not a mood-board dump.
- Include the product category, viewpoint, composition, form language, proportions, materials, finishes, key user-facing details, and the main design idea.
- Include believable construction cues where appropriate: seams, part breaks, material thickness, buttons, grips, hinges, vents, feet, handles, bezels, fasteners, gaskets, access panels, or overmold transitions.
- Make every visible feature imply a reason: usability, structure, assembly, protection, repair, feedback, grip, cooling, sealing, storage, or brand character.
- Avoid superficial styling and vague filler such as "sleek", "premium", "modern", "futuristic", or "beautiful" unless supported by specific form, material, finish, or construction decisions.
- Include the default render guardrails unless the user explicitly asks for a different scene, background, composition, or text.

Default render guardrails:
- Create a clean, ultra-realistic product render on a pure white or very clean studio background.
- Keep the product centered, well lit, fully visible, and presented with a polished commercial product-visualization look.
- Do not include text, labels, dimensions, annotations, diagrams, callouts, UI elements, captions, watermarks, logos, explanations, handwritten notes, people, clutter, props, scenery, dramatic environments, decorative backgrounds, or impossible floating parts unless the user explicitly asks for them.
- If the user asks for text, include only the exact requested text and keep it subtle and legible.
- For edits, preserve the previous image's product identity, materials, proportions, camera angle, composition, and white-background presentation unless the user asks to change them.
